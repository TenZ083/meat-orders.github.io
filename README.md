# Заказы мяса — GitHub Pages

Статическое приложение (без бэкенда). Работает на любом хостинге, включая бесплатный GitHub Pages.

## Как опубликовать
1. Создай репозиторий на GitHub (напр. `meat-orders`).
2. Загрузи **все файлы из этой папки** в корень репозитория:
   `index.html`, `admin.html`, `picker.html`, `razdelka.html`,
   `app.js`, `styles.css`, `manifest.json`.
   Быстрее всего — кнопка **Add file → Upload files**.
3. В настройках репо: **Settings → Pages** → «GitHub Actions» (или Build and deploy)
   → Deploy from branch → выбери ветку `main`, папку `/ (root)` → Save.
4. Через минуту получишь ссылку вида:
   `https://<твой-логин>.github.io/meat-orders/`

## Замечание про данные
Заказы хранятся в `localStorage` браузера. То есть каждый браузер/устройство видит
свои собственные заказы — админка и сборка на **одном** устройстве видят общие данные,
а с разных устройств данные не синхронизируются. Для общей таблицы нужен крошечный
бэкенд (Supabase/Firebase) — скажи, если нужно.
